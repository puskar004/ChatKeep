# ChatKeep

Private backup for chats **you export yourself**. Not WhatsApp. Deleting a chat in WhatsApp does not delete your ChatKeep copy.

## Download the Android app

1. Open the latest **Release** on this GitHub repo.
2. Download **ChatKeep.apk**.
3. On your phone: **Settings → Security → allow install from this source**.
4. Open the APK and tap **Install**.

This is a debug APK (not Play Store). Android will warn that it is from an unknown source — that is expected.

## Save a chat

1. Open WhatsApp.
2. Open the chat.
3. Tap the name (iPhone) or **⋮** (Android).
4. **Export chat** → **Without media**.
5. In ChatKeep tap **Import chat** and choose the `.txt` file.

Repeat for every chat you want to keep.

## Web / iPhone

Open `index.html` in Safari, then **Share → Add to Home Screen**.
